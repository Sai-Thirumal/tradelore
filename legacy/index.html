One-time Supabase Setup Required

Run this SQL in your Supabase SQL Editor, then refresh the page:

CREATE TABLE trade_orders (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  uid text UNIQUE NOT NULL,
  symbol text NOT NULL,
  exchange text DEFAULT '',
  trade_time text NOT NULL,
  order_id text DEFAULT '',
  trade_id text DEFAULT '',
  type text NOT NULL,
  qty numeric NOT NULL,
  price numeric NOT NULL,
  imported_at timestamptz DEFAULT now()
);

ALTER TABLE trade_orders ENABLE ROW LEVEL SECURITY;
CREATE POLICY "public_access" ON trade_orders
  FOR ALL USING (true) WITH CHECK (true);

After running, refresh and import your CSV.
